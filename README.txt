IMPERIO FRONT - Juego de estrategia territorial

1. Descomprime el ZIP.
2. Abre la carpeta imperio-front.
3. Haz doble clic en index.html para jugar en Chrome, Edge o Firefox.
4. No necesitas instalar nada ni tener Internet.

ARCHIVOS:
index.html = estructura de la página
style.css = apariencia y diseño
game.js = reglas, mapa, IA y controles

PARA PUBLICARLO:
Sube los tres archivos a un repositorio de GitHub y activa Settings > Pages > Deploy from a branch > main / root.

Esta es una versión original de un solo jugador, inspirada en juegos de conquista territorial.
